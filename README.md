## 🌟 Key Features

* **🗺️ 19-Phase Canonical Roadmap**:
  - Covers 70+ topics organized into 4 career stages: *Analyst Basics (P1–P4)*, *Strong Analyst (P5–P9)*, *Analytics Engineer (P10–P15)*, and *Final Projects & Interview Readiness (P16–P19)*.
  - Interactive checklists, topic details drawer, spaced repetition reinforcement engine, and evidence attachments.
* **💼 4 Production Capstone Projects**:
  - End-to-end industry projects covering E-commerce SQL/BI, Automated ETL Pipelines, Modern Cloud Data Warehouse (dbt + Snowflake/BigQuery), and Reverse ETL / Production Analytics.
* **📊 20-Skill Mastery Matrix**:
  - Dual-track scoring: Theory learning vs Hands-on practice with continuous log auditing.
* **⏱️ Focus Study Timer & Floating Pill**:
  - Wall-clock timestamp timer with Pomodoro presets (Free Flow, 15m Sprint, 25m Pomodoro, 45m Deep Work, 60m Mastery).
  - Non-intrusive floating dynamic island pill, session minimization, takeaway notes, and confidence ratings.
* **📅 Daily Execution & Spaced Repetition**:
  - Live calendar widget, 2026 horizon countdown, next best action engine with explainability, and daily task streaks.
* **👔 Job Tracker & Application Pipeline**:
  - Kanban pipeline stages from applied to offer, interview gaps logging, and milestone gates.
* **💾 Local-First Persistence**:
  - Real-time autosave to `localStorage`, JSON state backup, single-click restore, and clean-slate capability.
* **🌗 Zero-FOUC Dark/Light/System Themes**:
  - Pre-paint synchronous theme resolution with zero flash of light mode on page reloads.

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/santjsx/career-tarcker.git
cd career-tarcker
npm install
```

### 2. Run Local Dev Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Run Automated E2E Tests
```bash
npx playwright test
```

## 🌐 Deploy to Vercel

The application is pre-configured for instant zero-config deployment on [Vercel](https://vercel.com/):

1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. Import the repository into your Vercel dashboard.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
